# 🤖 Ai-Tutor: Your AI-Powered Learning Companion

Ai-Tutor is an advanced AI-powered educational assistant designed to revolutionize
learning and knowledge acquisition. Leveraging cutting-edge large language models
(LLMs) and a robust backend infrastructure, this platform transforms various forms
of content – from YouTube videos and PDFs to web articles – into interactive
learning experiences. It provides intelligent summarization, answers complex
questions, and offers personalized explanations, making complex subjects more
accessible and engaging.

Built on the powerful Django framework with a focus on a scalable API using
Django Rest Framework, Ai-Tutor integrates seamlessly with various AI services
like Google Generative AI, Groq, and Langchain. It incorporates tools for content
retrieval such as the YouTube Transcript API and Tavily Search for web resources.
The frontend, developed with React and Vite, provides a dynamic and responsive
user interface, ensuring a smooth and intuitive learning journey.

This comprehensive approach ensures that users have a dynamic and informed tutor
at their fingertips, capable of extracting, processing, and delivering information
efficiently. Ai-Tutor aims to empower students and lifelong learners by making
educational content more digestible, interactive, and tailored to individual needs.
User authentication is handled securely via Firebase, and content like PDFs are
stored reliably on Cloudinary.

## ✨ Features

*   **AI-Powered Explanations:** Get clear, concise explanations for any topic,
    generated by state-of-the-art AI models.
*   **Intelligent Content Summarization:** Automatically summarize lengthy YouTube
    videos, PDFs, and web articles into key takeaways.
*   **Interactive PDF Q&A:** Upload PDF documents and ask specific questions to
    receive instant, context-aware answers.
*   **YouTube Video Analysis:** Process YouTube video URLs to extract transcripts,
    summarize content, and answer questions directly from the video's information.
*   **Dynamic Chapter Generation:** Generate structured learning chapters on any
    given topic and grade level, complete with curated video and web resources.
*   **Multi-Video MCQ Generation:** Automatically create multiple-choice questions
    from a list of YouTube video URLs, perfect for self-assessment.
*   **Personalized Learning Paths:** Track your learning progress and review
    past conversations and generated content.
*   **Secure User Authentication:** Firebase-powered authentication ensures a
    secure and seamless login experience.
*   **Cloud-Based Content Storage:** PDFs are securely stored and managed using
    Cloudinary, ensuring accessibility and reliability.
*   **Responsive User Interface:** A modern and intuitive frontend built with
    React, Vite, and TailwindCSS for an optimal experience across devices.

## 🚀 Installation

Follow these steps to set up the Ai-Tutor project locally.

### Prerequisites

*   Python 3.9+
*   Node.js and npm (or yarn)
*   Git

### 1. Clone the Repository

```bash
git clone https://github.com/inevitablegs/Ai-Tutor.git
cd Ai-Tutor
```

### 2. Backend Setup (Django)

1.  **Create a Virtual Environment:**

    ```bash
    python -m venv venv
    source venv/bin/activate # On Windows: .\venv\Scripts\activate
    ```

2.  **Install Python Dependencies:**

    ```bash
    pip install -r requirements.txt
    ```

3.  **Environment Variables:**
    Create a `.env` file in the root directory (`Ai-Tutor/.env`) and populate
    it with your API keys and configuration details. See the Configuration
    section for required variables.

    ```dotenv
    # Example .env content (replace with your actual keys)
    DJANGO_SETTINGS_MODULE=decentral_tutor.settings
    SECRET_KEY='your_django_secret_key'
    DEBUG=True # Set to False in production

    # Google Generative AI (Gemini)
    GOOGLE_API_KEY='your_google_gemini_api_key'

    # Groq API
    GROQ_API_KEY='your_groq_api_key'

    # Tavily Search API
    TAVILY_API_KEY='your_tavily_api_key'

    # Firebase Admin SDK (Service Account Key JSON contents)
    # Ensure to replace '\\n' with actual newlines if copying directly
    FIREBASE_PROJECT_ID='your_firebase_project_id'
    FIREBASE_PRIVATE_KEY_ID='your_firebase_private_key_id'
    FIREBASE_PRIVATE_KEY='-----BEGIN PRIVATE KEY-----\nyour_private_key_content\n-----END PRIVATE KEY-----\n'
    FIREBASE_CLIENT_EMAIL='your_firebase_client_email'
    FIREBASE_CLIENT_ID='your_firebase_client_id'
    FIREBASE_CLIENT_CERT_URL='your_firebase_client_cert_url'

    # Cloudinary
    CLOUDINARY_CLOUD_NAME='your_cloudinary_cloud_name'
    CLOUDINARY_API_KEY='your_cloudinary_api_key'
    CLOUDINARY_API_SECRET='your_cloudinary_api_secret'

    # CORS Allowed Origins (for frontend)
    CORS_ALLOWED_ORIGINS=["http://localhost:5173"] # Adjust for production
    ```

4.  **Run Database Migrations:**

    ```bash
    python manage.py migrate
    ```

5.  **Start the Django Development Server:**

    ```bash
    python manage.py runserver
    ```
    The backend API will be available at `http://localhost:8000`.

### 3. Frontend Setup (React)

1.  **Navigate to the Frontend Directory:**

    ```bash
    cd frontend
    ```

2.  **Install Node.js Dependencies:**

    ```bash
    npm install
    # or yarn install
    ```

3.  **Environment Variables:**
    Create a `.env` file in the `frontend/` directory (`Ai-Tutor/frontend/.env`)
    and populate it with your Firebase client configuration and API base URL.

    ```dotenv
    # Example .env content (replace with your actual keys)
    VITE_API_BASE=http://localhost:8000/api # Match your Django backend URL

    # Firebase Client SDK Configuration
    VITE_FIREBASE_API_KEY='your_firebase_client_api_key'
    VITE_FIREBASE_AUTH_DOMAIN='your_firebase_auth_domain'
    VITE_FIREBASE_PROJECT_ID='your_firebase_project_id'
    VITE_FIREBASE_STORAGE_BUCKET='your_firebase_storage_bucket'
    VITE_FIREBASE_MESSAGING_SENDER_ID='your_firebase_messaging_sender_id'
    VITE_FIREBASE_APP_ID='your_firebase_app_id'
    VITE_FIREBASE_MEASUREMENT_ID='your_firebase_measurement_id'
    ```

4.  **Start the React Development Server:**

    ```bash
    npm run dev
    # or yarn dev
    ```
    The frontend application will typically open in your browser at
    `http://localhost:5173`.

## 💡 Usage

Ai-Tutor provides a seamless way to interact with educational content.

### Via the Frontend Application

Once both the backend and frontend servers are running, navigate to the frontend
URL (e.g., `http://localhost:5173`).

1.  **Login:** Authenticate using Firebase.
2.  **Upload PDF:** Go to the PDF section, upload your document, and start
    asking questions.
3.  **Analyze YouTube Video:** Paste a YouTube video URL to get a summary, ask
    questions, or generate quizzes.
4.  **Generate Chapters:** Provide a topic and grade level to receive a structured
    study plan with curated resources.
5.  **Generate MCQs:** Input multiple YouTube video URLs to generate
    multiple-choice questions covering the content.

### Via API (Example: Generate Multi-Video MCQs)

You can also interact with the backend API directly. Here's an example using
`curl` to generate MCQs from multiple YouTube videos, similar to how the
`test.py` script operates:

First, ensure you have a valid Firebase ID Token for authentication. You would
typically obtain this after a user logs in via the frontend.

```bash
# Replace <YOUR_FIREBASE_ID_TOKEN> with an actual token
# Replace the video URLs with relevant ones for your test

curl -X POST \
  http://localhost:8000/api/generate-multi-mcqs/ \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <YOUR_FIREBASE_ID_TOKEN>' \
  -d '{
    "video_urls": [
```

## ⚙️ Configuration

Environment variables are crucial for the application to function correctly.
Ensure both `.env` files (root and `frontend/`) are set up as described in
the Installation section.

### Backend (`Ai-Tutor/.env`)

| Variable                       | Description                                | Required |
| :----------------------------- | :----------------------------------------- | :------- |
| `DJANGO_SETTINGS_MODULE`       | Path to Django settings (e.g., `decentral_tutor.settings`) | Yes |
| `SECRET_KEY`                   | Django secret key for security.            | Yes      |
| `DEBUG`                        | `True` for development, `False` for production. | Yes |
| `GOOGLE_API_KEY`               | API key for Google Generative AI (Gemini). | Yes      |
| `GROQ_API_KEY`                 | API key for Groq LLM services.             | Yes      |
| `TAVILY_API_KEY`               | API key for Tavily Search API.             | Yes      |
| `FIREBASE_PROJECT_ID`          | Firebase project ID for Admin SDK.         | Yes      |
| `FIREBASE_PRIVATE_KEY_ID`      | Firebase private key ID for Admin SDK.     | Yes      |
| `FIREBASE_PRIVATE_KEY`         | Firebase private key (with `\n` replaced). | Yes      |
| `FIREBASE_CLIENT_EMAIL`        | Firebase client email for Admin SDK.       | Yes      |
| `FIREBASE_CLIENT_ID`           | Firebase client ID for Admin SDK.          | Yes      |
| `FIREBASE_CLIENT_CERT_URL`     | Firebase client certificate URL.           | Yes      |
| `CLOUDINARY_CLOUD_NAME`        | Your Cloudinary cloud name.                | Yes      |
| `CLOUDINARY_API_KEY`           | Your Cloudinary API key.                   | Yes      |
| `CLOUDINARY_API_SECRET`        | Your Cloudinary API secret.                | Yes      |
| `CORS_ALLOWED_ORIGINS`         | Comma-separated list of allowed origins (e.g., `["http://localhost:5173"]`). | Yes |

### Frontend (`Ai-Tutor/frontend/.env`)

| Variable                       | Description                                | Required |
| :----------------------------- | :----------------------------------------- | :------- |
| `VITE_API_BASE`                | Base URL for the Django backend API.       | Yes      |
| `VITE_FIREBASE_API_KEY`        | Firebase client API key.                   | Yes      |
| `VITE_FIREBASE_AUTH_DOMAIN`    | Firebase auth domain.                      | Yes      |

## 🛠️ Technologies

### Core Stack

| Category  | Technology             | Description                                |
| :-------- | :--------------------- | :----------------------------------------- |
| **Backend** | Python                 | Primary programming language.              |
|           | Django                 | High-level Python web framework.           |
|           | Django REST Framework  | Toolkit for building Web APIs with Django. |
|           | PostgreSQL / SQLite    | Database for storing application data.     |
| **Frontend** | React                | JavaScript library for building UIs.       |
|           | Vite                   | Fast frontend build tool.                  |
|           | JavaScript / HTML / CSS | Core web technologies.                     |
|           | TailwindCSS            | Utility-first CSS framework.               |
| **AI/ML** | Google Generative AI   | LLM for text generation and embeddings.    |
|           | Groq                   | High-performance LLM inference engine.     |
|           | Langchain              | Framework for developing LLM applications. |
|           | FAISS-CPU              | Library for efficient similarity search.   |
| **External Services** | Firebase       | User authentication and analytics.         |
|           | Cloudinary             | Cloud-based image and video management (for PDFs). |
|           | YouTube Transcript API | Extracts transcripts from YouTube videos.  |
|           | Tavily Search          | AI-powered search API for web content.     |
| **Deployment** | Gunicorn           | WSGI HTTP Server for UNIX (production).    |
|           | Whitenoise             | Serves static files for Django apps.       |

### Explanation of Key Technologies

*   **Python & Django:** Python is the backbone, and Django provides a robust,
    secure, and scalable framework for building the backend API. It handles
    database interactions, user management, and API routing.
*   **Django REST Framework (DRF):** Extends Django to simplify the creation of
    powerful and flexible RESTful APIs, enabling the frontend to communicate
    seamlessly with the backend logic.
*   **React & Vite:** React is used for building the interactive and dynamic
    user interface. Vite provides an extremely fast development experience
    with instant hot module replacement and optimized builds.
*   **Google Generative AI (Gemini) & Groq:** These are the large language
    models powering the AI capabilities. Gemini provides powerful text
    generation and embeddings for understanding content, while Groq offers
    lightning-fast inference for rapid responses.
*   **Langchain:** A framework that orchestrates the interactions between LLMs,
    external data sources (like YouTube transcripts or PDFs), and various
    tools, making it easier to build complex AI applications.
*   **Firebase:** Utilized for secure user authentication, managing user
    accounts, and potentially analytics, providing a reliable and scalable
    identity management solution.
*   **Cloudinary:** Handles the storage and delivery of uploaded PDF files,
    reducing the load on the backend server and providing robust media management.
*   **YouTube Transcript API & Tavily Search:** These tools are crucial for
    content ingestion. The YouTube Transcript API fetches textual content
    from videos, and Tavily Search allows the AI to find and incorporate
    relevant web resources into generated chapters and answers.
*   **TailwindCSS:** A utility-first CSS framework that speeds up UI
    development by providing low-level utility classes, allowing for highly
    customizable and responsive designs.
