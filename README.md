## Project Overview

Ai-Tutor is an advanced AI-powered educational assistant designed to revolutionize learning and knowledge acquisition. Leveraging cutting-edge large language models (LLMs) and a robust backend infrastructure, this platform transforms various forms of content – from YouTube videos and PDFs to web articles – into interactive learning experiences. It provides intelligent summarization, answers complex questions, and offers personalized explanations, making complex subjects more accessible and engaging.

Built on the powerful Django framework with a focus on a scalable API using Django Rest Framework, Ai-Tutor integrates seamlessly with various AI services like Google Generative AI, Groq, and Langchain, along with tools for content retrieval like YouTube Transcript API and Tavily Search. This comprehensive approach ensures that users have a dynamic and informed tutor at their fingertips, capable of extracting, processing, and delivering information efficiently.

## Features

*   **AI-Powered Explanations:** Get clear, concise explanations for any topic, generated by state-of-the-art AI models.
*   **Content Summarization:** Automatically summarize long articles, PDFs, and YouTube video transcripts to quickly grasp key information.
*   **Intelligent Q&A:** Ask follow-up questions or explore related concepts with an AI that understands context and provides accurate answers.
*   **Multi-Source Information Retrieval:** Integrates with YouTube, web search (Tavily), and local documents (PDFs) to pull relevant information for comprehensive responses.
*   **Fast & Efficient Processing:** Utilizes high-performance LLMs like Groq for rapid response times.
*   **User Authentication & Management:** Secure user accounts powered by Django REST Framework Simple JWT and Firebase Admin.
*   **Scalable API Backend:** A robust Django REST Framework backend designed for easy integration with front-end applications.
*   **Cloud Storage Integration:** Seamless media management and storage using Cloudinary.

## Installation

Follow these steps to set up Ai-Tutor on your local machine.

### Prerequisites

*   Python 3.9+
*   pip (Python package installer)
*   Git

### Steps

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/your_username/Ai-Tutor.git
    cd Ai-Tutor
    ```

2.  **Create a Virtual Environment:**
    It's highly recommended to use a virtual environment to manage dependencies.
    ```bash
    python -m venv venv
    ```

3.  **Activate the Virtual Environment:**
    *   **On macOS/Linux:**
        ```bash
        source venv/bin/activate
        ```
    *   **On Windows:**
        ```bash
        venv\Scripts\activate
        ```

4.  **Install Dependencies:**
    Install all required Python packages from `requirements.txt`.
    ```bash
    pip install -r requirements.txt
    ```

5.  **Apply Database Migrations:**
    Initialize the database schema.
    ```bash
    python manage.py migrate
    ```

6.  **(Optional) Create a Superuser:**
    This is useful for accessing the Django admin panel.
    ```bash
    python manage.py createsuperuser
    ```

## Configuration

Ai-Tutor relies on environment variables for sensitive information and API keys.

1.  **Create a `.env` file:**
    In the root directory of the project (where `manage.py` is located), create a file named `.env`.

2.  **Populate `.env`:**
    Add the following variables to your `.env` file. Replace the placeholder values with your actual keys and settings.

    ```dotenv
    SECRET_KEY=your_django_secret_key_here
    DEBUG=True # Set to False in production
    ALLOWED_HOSTS=127.0.0.1,localhost # Add your domain in production

    # Google Generative AI / Gemini API
    GOOGLE_API_KEY=your_google_ai_studio_api_key

    # Groq API
    GROQ_API_KEY=your_groq_api_key

    # Tavily API (for advanced web search capabilities)
    TAVILY_API_KEY=your_tavily_api_key

    # Firebase Admin SDK (for authentication/user management if used)
    # You'll typically store the path to your service account key file
    FIREBASE_SERVICE_ACCOUNT_KEY_PATH=/path/to/your/firebase-service-account.json

    # Cloudinary Credentials (for media storage)
    CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
    CLOUDINARY_API_KEY=your_cloudinary_api_key
    CLOUDINARY_API_SECRET=your_cloudinary_api_secret

    # CORS Headers (adjust as needed for frontend integration)
    CORS_ALLOWED_ORIGINS=http://localhost:3000,http://127.0.0.1:3000 # Add your frontend URLs
    ```
    *Tip:* For `SECRET_KEY`, you can generate one using Python: `import os; print(os.urandom(48).hex())`

## Usage

After completing the installation and configuration, you can run the Ai-Tutor backend server.

### Running the Development Server

```bash
python manage.py runserver
```
The server will typically start at `http://127.0.0.1:8000/`.

### Interacting with the Application

Ai-Tutor is primarily an API-driven backend. You can interact with it via:

*   **Web Browser (for basic endpoints and Django Admin):**
    *   `http://127.0.0.1:8000/admin/` (Django Admin panel)
    *   `http://127.0.0.1:8000/api/` (Django REST Framework browsable API, if enabled)

*   **API Clients (e.g., Postman, Insomnia, curl):**
    You will send requests to the various API endpoints provided by the application.
    For example, to interact with a theoretical `chat` or `summarize` endpoint:

    ```bash
    # Example: Summarize a YouTube video (conceptual)
    curl -X POST http://127.0.0.1:8000/api/summarize-youtube/ \
         -H "Content-Type: application/json" \
         -d '{"video_url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ"}'

    # Example: Ask the AI a question (conceptual)
    curl -X POST http://127.0.0.1:8000/api/ask-ai/ \
         -H "Content-Type: application/json" \
         -d '{"question": "Explain the concept of quantum entanglement simply."}'
    ```
    *Note:* The exact API endpoints will depend on the `core/api.py` and other application logic defined within the project.
